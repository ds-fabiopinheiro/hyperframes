Notas do slide original 23

Relatório x IA (4 min). A diferença mais contraintuitiva: o processo tradicional de qualidade de dados remove anomalias e outliers — exatamente o que um modelo de IA precisa ver para aprender. Em fraude, falhas de rede ou picos de demanda, o outlier não é ruído: é o sinal (Foundations of AI-Ready Data). Resumo da Gartner: analytics tradicional prioriza precisão estática; dado pronto para IA prioriza representatividade dinâmica. Outras diferenças:
• Avaliação contínua: observabilidade de dados (drift entre treino e produção, completude, atualidade, versões) para pegar a degradação antes que o modelo falhe (AI Leaders: Maturity Guide for AI Data).
• Metadados viram infraestrutura: linhagem, dono, confidencialidade, catálogo de features.
• Governança orientada a risco: teste de viés por instância, rastrear inferências até os dados de origem, reuso controlado de dados aprovados.
• Versionamento de dados, pipelines, features e modelos para reproduzir e auditar resultados. Implicação para o gestor: "nosso BI é confiável" não significa "nossos dados estão prontos para IA". Pergunte sempre: pronto para qual caso de uso?

Quando não usar IA generativa

Previsão numérica
✕Não use GenAI: Previsão numérica e planejamento (receita, demanda, capacidade)
✓Use: Modelo preditivo: modelos de linguagem não foram feitos para precisão numérica
Decisão crítica
✕Não use GenAI: Decisão crítica como ferramenta principal (fraude, crédito, alerta de segurança)
✓Use: Preditiva decide; a generativa explica e comunica
Modelo que funciona
✕Não use GenAI: Substituir um modelo preditivo que já funciona
✓Use: Mantenha o modelo; use GenAI para resumir e comunicar o resultado
Regras fixas
✕Não use GenAI: Regras determinísticas (aplicar a mesma política para todos)
✓Use: Motor de regras ou automação simples
Dado sensível
✕Não use GenAI: Dado sensível fora de um ambiente aprovado
✓Use: Só ferramentas autorizadas, com governança e controle de acesso

Notas do slide original 21

Quando não usar GenAI (5 min). A Gartner é enfática: IA generativa não deve ser a escolha padrão. Organizações desperdiçam recursos aplicando GenAI onde preditiva — ou nenhuma IA — seria melhor (When Not to Use Generative AI; CIO Leadership Mistakes: Fixating on GenAI and Agentic AI). Por que cada linha: 1. Previsão numérica: modelos de linguagem podem dar respostas numéricas erradas com total confiança. 2. Decisões críticas: alucinação é inaceitável quando há dinheiro, pessoas ou conformidade em jogo. A GenAI entra para explicar a decisão do modelo preditivo, não para decidir. 3. Modelo que já funciona: acrescentar GenAI "para modernizar" só adiciona custo e complexidade. 4. Regras determinísticas: políticas pedem consistência; a natureza probabilística da GenAI vai contra isso. 5. Dado sensível: só em ambientes aprovados, com governança de dados e controle de acesso. Exemplo para discutir: "um gerente quer usar um chatbot para calcular o reajuste de contratos". Resposta: o cálculo é regra (planilha ou sistema); a GenAI pode, no máximo, redigir a comunicação ao cliente com o valor calculado pelo sistema. Pergunta: "Alguma ideia da lista de vocês caiu em uma destas linhas?"
